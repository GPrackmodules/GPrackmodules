<h1>GPrackmodules Change Log</h1>

<h2>Version 2.2.0</h2>
Date: t.b.d.

<h4>New Modules</h4>

  * **DualControl** and **Triple Control** — control your mono-or polyphonic synth from two or three 
keyboards, MPE controllers and/or sequencers simultaneously.
  * **Clamp** — Limit notes to a V/Oct range. Drop, limit or octave-shift out-of-range notes.
  * **Extended Channel** module for **Chained Mixer** — input channel with Direct Out, additional 
controls and CV control.

<h4>Updates</h4>

  * **Chained Mixer Main** Module: added OVR light with a configurable dB threshold.
  * **Chained Mixer**: added CTRL/CMD and SHIFT key modifiers on Mute and Solo buttons, inspired
by the MindMeld MixMaster modules.
  * **Chained Mixer**: made all Mute and Solo operations click-free with a 30 ms fade.
  * **Stereo Chorus**: fixed Bypass audio.
  * **Rotary**: reduced output level in Bypass mode to better match processed audio.

<h2>Version 2.1.0</h2>
Date: Feb 15, 2026

<h4>New Modules</h4>

  * New Module **Rotary** — a rotating speaker simulation
  * New module **AB8** — an 8-channel A/B switcher for audio and CV

<h4>Updates</h4>

  * **Stereo Chorus**: CPU optimizations
  * **AB4**: CV output reflecting A/B state
  * **Chained Mixer Main**: fixed dead output if only the right output was connected

<h2>Version 2.0.1</h2>
Date: Jun 29, 2025

<h4>Updates</h4>

* **AB4**: added CV input for A/B switching
* **AB4**: Deleted duplicate "Switch" tag in plugin.json
* **Chained Mixer**: eliminated warning messages about a missing SVG file in the RACK log
* **Chained Mixer**: Implemented text editing for Aux-Send and Fader parameters
* **Stereo Chorus**: Implemented text editing for RATE parameter
